# Odin's Eye: правила проекта

- Перед коммитом: скилл `verify` (`.claude/skills/verify`). Перед копированием в `/Applications`, перед `Scripts/release.sh`, `dmg.sh`, `notarize.sh` и пушем тега: `verify` и скилл `predeploy-check`. Блокер из отчёта останавливает выкладку, пока Дамир не скажет «выкатывай так».
- В `/Applications` только через `Scripts/install-local.sh`: он сохраняет прошлую версию для отката.
- Предпросмотр, E2E и отладочные запуски только с `ODINSEYE_SUPPORT_DIR=<временная папка>`. Без него они пишут в настоящий `config.json` и забирают сокет агента у работающего приложения.
- Настройки пишутся через `ConfigStore` (слияние с диском). Не писать `config.json` в обход.
- Баг, дошедший до Дамира: сначала тест, который падает, потом починка. Тесты и код, который они проверяют, не менять в одном коммите без объяснения.
- Сообщение коммита заканчивается строкой `Verified: <что прогнано>`.
