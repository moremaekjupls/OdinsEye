# Odin's Eye

Чёлка MacBook как рабочая панель: навёл курсор — открылась, увёл — спряталась, а при необходимости есть возможность закрепить ее для того, чтобы закинуть файлы.
Плеер, полка для файлов, история буфера обмена, заготовки, конвертер валют и
режим «Не спать».

## Установка

1. Откройте [последний релиз](../../releases/latest) и скачайте
   `OdinsEye-<версия>.dmg` из раздела **Assets**.
2. Откройте образ и перетащите **Odin's Eye** в «Программы».
3. Запустите. Если сборка без подписи Apple (заметки к релизу это говорят),
   при первом запуске macOS откажется её открыть: нажмите **Готово**, затем
   **Системные настройки → Конфиденциальность и безопасность** → внизу
   **«Всё равно открыть»**.

Нужна macOS 15 или новее и MacBook с чёлкой: панель стоит только на встроенном
экране с вырезом. С закрытой крышкой и внешним монитором панели нет — она
вернётся, когда крышку откроют.

В меню-баре приложения нет: оно живёт в чёлке. Выйти — **Настройки →
«Выйти из Odin's Eye»**; открыть панель без наведения — запустить Odin's Eye
ещё раз из «Программ» или Spotlight.

## Вкладки

| Вкладка | Что делает |
|---|---|
| **Музыка** | Обложка, трек, перемотка, пауза и переключение — для любого источника, который видит macOS, включая вкладки браузера |
| **Полка** | Файлы, перетащенные в чёлку; скриншоты из буфера (и с айфона) и из папки скриншотов. Без лимита |
| **Буфер** | История копирований без лимита, переживает перезапуск. Булавка на строке закрепляет запись: закреплённые стоят сверху и не удаляются «Очистить» |
| **Заготовки** | Ручной список того, что надоело набирать; хранится в `snippets.json`, правится и руками |
| **Валюта** | Конвертер по дневным курсам — единственное, что ходит в сеть |
| **Настройки** | Автозапуск, иконка, видимость вкладок, скриншоты, «Не спать» |

Справа в панели две кнопки:

- **Булавка** — панель не сворачивается, когда уходит курсор. Снять: нажать
  ещё раз или Esc (Esc доходит до панели, пока фокус в ней).
- **Чашка — «Не спать»**, как Amphetamine: бессрочно, 1, 2 или 4 часа
  (правый клик по чашке). Оставшееся время под чашкой. «Не гасить экран»
  держит дисплей, без него — только систему. Пока режим включён, в меню-баре
  стоит чашка — её меню управляет режимом; выключили — чашка пропала. После
  перезапуска режим выключен. С закрытой крышкой на
  батарее без монитора мак всё равно уснёт — это решает не приложение.

Копии из менеджеров паролей в историю буфера не попадают.

## Разрешения

Никаких по умолчанию. Автоматизацию для Music и Spotify macOS спросит, только
если основной путь управления музыкой перестанет работать.

## Где лежат данные

| Что | Где |
|---|---|
| Настройки, заготовки, история буфера | `~/Library/Application Support/OdinsEye/` (`config.json`, `snippets.json`, `clipboard.json`) |
| Скриншоты из буфера | `~/Pictures/OdinsEye` |
| Полка, папка скриншотов | настройки macOS приложения `com.moremaekjupls.odinseye` |

`clipboard.json` — всё, что копировалось, открытым текстом; файл доступен
только владельцу.

## Выпуск версии

Поднять номер в `Scripts/version` — и всё: workflow **release** сам прогонит
тесты, соберёт образ и выложит релиз. Выпустить текущий номер вручную —
**Actions → release → Run workflow**.

Каждый пуш проверяет workflow **build**: тесты, сборку, запуск приложения.
Готовое приложение из каждой сборки лежит в её **Artifacts**.

## Подпись и нотаризация

Чтобы macOS открывала приложение сразу, без «Всё равно открыть», сборку нужно
подписать сертификатом **Developer ID** и нотаризовать. Для этого нужна
платная подписка [Apple Developer Program](https://developer.apple.com/programs/).
Workflow **release** делает всё сам, если в **Settings → Secrets and variables
→ Actions** есть секреты:

| Секрет | Что это |
|---|---|
| `DEVELOPER_ID_P12` | сертификат Developer ID Application с ключом, `.p12` в base64 |
| `DEVELOPER_ID_P12_PASSWORD` | пароль от этого `.p12` |
| `NOTARY_KEY_P8` | ключ App Store Connect API, `.p8` в base64 |
| `NOTARY_KEY_ID` | Key ID этого ключа |
| `NOTARY_ISSUER_ID` | Issuer ID |

## Сборка у себя

Нужен **Xcode** (с macOS 27 одних Command Line Tools не хватает — в них нет
макросов SwiftUI):

```bash
./Scripts/bundle.sh && open build/OdinsEye.app   # сборка
./Scripts/test.sh                                # тесты
python3 Scripts/make-icons.py                    # перерисовать иконки
```
